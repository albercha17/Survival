# La Arena

Simulador de supervivencia por rondas (estilo Juegos del Hambre), pensado para iPhone. Añade tributos y cada día ocurren muertes, alianzas, traiciones y amoríos aleatorios hasta que queda un ganador.

Web estática: abre `index.html` o publícala con GitHub Pages. El progreso se guarda en `localStorage`.
